COMPARADOR DE ALGORITMOS DE ORDENAMIENTO
Programa con interfaz gráfica (tkinter) que genera un array aleatorio y compara 8 algoritmos de ordenamiento mostrando pasos y tiempo en nanosegundos.
Algoritmos
Bubble Sort, Selection Sort, Insertion Sort, Merge Sort, Quick Sort, Heap Sort, Shell Sort, Counting Sort.
Requisitos
•	Tkinter 
•	Python 
Cómo correr
Se ejecuta el código, se abre una ventana. Ingresa la cantidad de números, el mínimo y el máximo del rango, y presiona Ejecutar.
Ejemplos
Ejemplo 1 — 15 números entre 1 y 100
Cantidad: 15   Mínimo: 1   Máximo: 100 
Ejemplo 2 — 1000 números entre 1 y 10000
Cantidad: 1000   Mínimo: 1   Máximo: 10000
